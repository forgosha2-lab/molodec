# Crash Game - Инструкция

## Описание
Анимированная страница игры Crash с НЛО.

## Файлы в архиве:
- crash_game.html - основной HTML файл с игрой
- ufo.png - изображение НЛО
- README.txt - этот файл

## Как использовать:
1. Распакуйте все файлы в одну папку
2. Откройте файл crash_game.html в браузере
3. Нажмите кнопку "НАЧАТЬ ИГРУ"

## Особенности:
- Фаза ожидания с облаками
- Анимация роста множителя с графиком
- НЛО движется по траектории
- При достижении 3x фон меняется на космический с планетами
- Пульсация множителя при достижении целых значений
- Автоматический рестарт игры

## Технологии:
- HTML5
- CSS3 анимации
- JavaScript Canvas для графика

Приятной игры!
