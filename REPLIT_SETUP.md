# Инструкция по загрузке проекта PPYLSE на Replit

## Автоматический импорт из GitHub

### Метод 1: Быстрый импорт (Rapid Import)
Просто откройте следующий URL в браузере (замените на ваш репозиторий):
```
https://replit.com/github/ВАШ_ПОЛЬЗОВАТЕЛЬ/НАЗВАНИЕ_РЕПОЗИТОРИЯ
```

### Метод 2: Пошаговый импорт (Guided Import)
1. Откройте https://replit.com/import
2. Выберите "GitHub" из доступных источников
3. Подключите свой GitHub аккаунт (если еще не подключен)
4. Выберите репозиторий PPYLSE
5. Нажмите "Import" для начала импорта

## Автоматическая настройка проекта

После импорта Replit автоматически:
- ✅ Установит все зависимости из `package.json`
- ✅ Настроит workflow для запуска проекта (кнопка Run)
- ✅ Создаст PostgreSQL базу данных (Neon)
- ✅ Установит переменные окружения (DATABASE_URL и др.)

## Проверка настройки

После импорта проверьте:

### 1. База данных
- Должна автоматически создаться PostgreSQL база данных
- Переменные окружения `DATABASE_URL`, `PGHOST`, `PGPORT` должны быть установлены

### 2. Workflow
- Должен быть настроен workflow "app" с командой `bun run start`
- При запуске должны стартовать frontend (порт 5000) и backend (порт 3003)

### 3. Первый запуск
Нажмите кнопку "Run" и подождите:
1. Установку зависимостей (~30 секунд)
2. Создание таблиц в базе данных (автоматически)
3. Запуск сервера и фронтенда

## Если что-то пошло не так

### База данных не создана
1. Откройте вкладку "Database" в левой панели
2. Нажмите "Create Database"
3. Выберите "PostgreSQL (Neon)"
4. Перезапустите проект

### Workflow не настроен
1. Откройте вкладку "Workflows" 
2. Должен быть workflow "app" с командой `concurrently "bun run server" "bun run dev"`
3. Если его нет, просто нажмите Run - он создастся автоматически

### Таблицы не создаются
Таблицы создаются автоматически при первом запуске сервера. Если возникли проблемы:
1. Проверьте консоль на ошибки
2. Убедитесь, что переменная `DATABASE_URL` установлена
3. Перезапустите проект

## Структура проекта

```
ppylse-game-hub/
├── src/                    # Frontend React код
├── server/                 # Backend Node.js код
│   ├── index.ts           # Главный сервер (PostgreSQL + Express)
│   ├── db.ts              # Конфигурация Drizzle ORM
│   ├── crash-websocket.js # WebSocket для Crash игры
│   ├── websocket-uno.js   # WebSocket для UNO игры
│   └── durak-server.js    # Логика игры Дурак
├── shared/                 # Общий код
│   └── schema.ts          # Drizzle ORM схема базы данных
├── package.json           # Зависимости проекта
├── drizzle.config.ts      # Конфигурация Drizzle
└── .replit                # Конфигурация Replit (автосоздается)
```

## Технологии

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Shadcn/ui
- **Backend**: Node.js, Express, WebSocket (ws)
- **Database**: PostgreSQL (Neon) с Drizzle ORM
- **Runtime**: Bun (быстрая альтернатива Node.js)

## Полезные команды

```bash
# Запуск проекта (frontend + backend)
bun run start

# Только frontend (порт 5000)
bun run dev

# Только backend (порт 3003)
bun run server

# Работа с базой данных
bun run db:push      # Синхронизация схемы с БД
bun run db:generate  # Генерация миграций
bun run db:studio    # Открыть Drizzle Studio (GUI для БД)
```
